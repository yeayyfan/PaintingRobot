# 船舶自动喷漆机器人展示页面

这是一个用于展示工业机器人（船舶自动喷漆机器人）的**多页面**静态网站项目。

## 📁 项目结构

```
homepage/
├── index.html      # 首页
├── features.html   # 产品特点页面
├── specs.html      # 技术参数页面
├── gallery.html    # 展示图库页面
├── contact.html    # 联系我们页面
├── styles.css      # 全局样式表文件
├── script.js       # JavaScript交互脚本
└── README.md       # 项目说明文档
```

## ✨ 功能特点

### 页面结构（多页面）
- **index.html**：首页，展示产品主题和应用场景
- **features.html**：产品特点页面，6个核心特点 + 优势对比
- **specs.html**：技术参数页面，详细的技术规格表格
- **gallery.html**：展示图库页面，6个产品展示项目
- **contact.html**：联系我们页面，联系信息和咨询表单

### 交互功能
- ✅ **多页面结构**：点击导航菜单重新加载页面（非单页应用）
- ✅ **导航高亮**：当前页面在导航栏中高亮显示
- ✅ **悬停动画**：卡片和按钮的悬停效果
- ✅ **表单处理**：联系表单提交功能
- ✅ **响应式设计**：支持手机、平板、桌面设备
- ✅ **滚动动画**：元素滚动到视口时淡入
- ✅ **页面过渡**：页面加载时的淡入效果

## 🚀 使用方法

### 方法1：直接打开
1. 下载所有文件到同一目录
2. 双击 `index.html` 文件
3. 在浏览器中查看页面
4. 点击导航菜单在不同页面间切换

### 方法2：使用本地服务器（推荐）
```bash
# 使用 Python 3
cd C:\Work\GitClone\ase-technique\homepage
python -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js (需要安装 http-server)
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

### 方法3：使用VS Code Live Server
1. 在VS Code中打开项目文件夹
2. 右键点击 `index.html`
3. 选择 "Open with Live Server"

### 方法4：Windows快捷方式
```bash
start C:\Work\GitClone\ase-technique\homepage\index.html
```

## 📝 自定义说明

### 修改内容
- 在各个 HTML 文件中修改对应页面的文本内容
- 在 `styles.css` 中调整全局样式和颜色
- 在 `script.js` 中添加或修改交互功能

### 颜色主题
主要使用的渐变色：
- 主色：`#667eea` 到 `#764ba2`
- 可在 CSS 中全局替换以更改主题色

### 添加新页面
1. 复制现有页面（如 `features.html`）
2. 修改页面内容
3. 更新所有页面的导航链接
4. 在 CSS 中添加页面特定样式（如需要）

### 添加实际图片
1. 创建 `images/` 目录
2. 将图片文件放入该目录
3. 在 HTML 中替换渐变背景为实际图片路径
4. 使用 `data-src` 属性实现懒加载（已在 script.js 中实现）

## 💡 开发提示

### 多页面 vs 单页面
本项目采用**多页面架构**：
- ✅ 每个页面独立的HTML文件
- ✅ 点击导航链接会重新加载页面
- ✅ 更好的SEO优化
- ✅ 更简单的维护和扩展
- ✅ 适合内容较多的展示网站

### 表单提交
这是一个纯静态页面，表单提交功能需要后端支持。如需实现真实的表单提交，可以：
1. 配置后端API（如 Node.js、PHP等）
2. 使用第三方服务（如 Formspree、EmailJS、Netlify Forms等）
3. 集成到现有的CMS系统

---

**注意**：本项目为静态HTML网站，所有页面都是独立的HTML文件，点击导航菜单会重新加载页面。
